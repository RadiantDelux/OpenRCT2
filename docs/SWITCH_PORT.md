# Nintendo Switch port

Initial port target:

- Build with devkitPro and libnx.
- Produce an .nro homebrew executable.
- Use SDL2 rendering first.
- Disable optional desktop-only services during first bring-up.
- Add Switch input mapping after the first bootable build.

The original Switch port is used as a reference for packaging, data paths and controls, but this branch targets the current OpenRCT2 codebase.
